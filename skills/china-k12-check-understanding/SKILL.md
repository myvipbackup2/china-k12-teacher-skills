# China K12 Check for Understanding

CFU 的目的不是打分，而是让老师读出学生当前理解并决定下一步教学。

## 1. 聚焦一个学习组件

一次只检查一个真正关键的理解或技能。主题太大时，选择最影响后续学习、且 1–3 题能诊断的组件。只有选择会显著改变题目时才向老师确认。

## 2. 使用真实误解

优先使用：
1. 当前课程/老师提供的学生错误；
2. 匹配 Profile 的 misconception reference；
3. 学科上合理、可解释的典型错误推理。

每个错误选项或错误操作必须来自一条真实可能的思路，不能只是明显搞笑的错答案。

## 3. 小而诊断性强

默认 1–3 个，约 5 分钟内可完成。按目标选择：
- 情境判断 + 理由
- 预测结果
- 找错 / 修错
- 排序步骤
- 选择最佳方案并解释
- 看操作记录定位问题
- 极短开放回答

学生文本按年级控制复杂度，不把多个抽象条件塞进一题。

## 4. 教师读数指南

每题必须告诉老师：
- 理想回答中的关键证据
- 主要错误回答反映的具体思维
- 下一步教学动作：追问、重新表示、小任务或演示

描述可观察思维，不写“能力差、基础弱、学不会”。

## 5. 质量门

交付前逐题检查：
- 是否可能两个答案都合理？如果是，重写。
- 干扰项是否真有学生可能这样想？如果不是，重写。
- 是否只检查定义记忆？如果是，尽量升级为应用/解释。
- 老师能否根据答案决定下一步？如果不能，这不是好的 CFU。
