# 小学信息科技常见误解库

用于课堂追问、CFU 干扰项、课前准备和纠错活动。它们是诊断假设，不是对某个学生的标签。

- `删除桌面图标 = 删除软件`：区分快捷方式、应用本体和文件。
- `快捷方式 = 原文件`：通过移动/删除快捷方式观察原文件是否仍存在。
- `文件夹和文件没有区别`：用“容器/内容”任务诊断。
- `浏览器 = 搜索引擎`：让学生分别指出浏览器、网址、搜索服务扮演的角色。
- `Wi‑Fi = 互联网`：设计“连接局域网但外网不可用”的情境。
- `密码复杂就可以所有网站重复使用`：讨论泄露后的连锁风险。
- `网上图片都可以随便用`：引入来源、授权、版权与责任。
- `数据就是数字`：用文字、图片、日期、选项等记录作为反例。
- `变量就是数学未知数`：强调程序中的值可以被命名、读取和更新。
- `循环只是为了少写几行`：继续检查是否理解重复规则、次数或终止条件。
- `Scratch 积木永远从上到下全部执行`：用事件、多角色、条件或并行脚本纠正。
- `AI 给出的答案一定正确`：用可核验错误输出诊断。
- `AI 像人一样真正理解所有内容`：区分模型生成与人的经验、责任和判断。
- `AI 生成内容就可以随便使用`：讨论版权、来源、隐私和责任。
