# 上海小学信息科技：学生语言规则

## 三至四年级

- 一次优先只引入一个核心新概念。
- 先例子/现象，后术语。
- 单句尽量短，少连续从句。
- 避免连续出现多个未解释术语。
- 每个抽象概念尽量给：生活例子 + 信息科技例子 + 立即可做的小任务。
- 不用“显而易见、众所周知、赋能、底层逻辑、范式”等成人表达。

推荐：`体验 → 观察 → 猜 → 动手 → 说规律 → 给名字`。

## 五至六年级

可以逐步增加正式术语和因果解释，但仍优先：
`真实问题 → 猜想 → 操作验证 → 提炼规律 → 正式概念 → 新情境迁移`。

重要概念尽量回答：What / Why / How / Try。

## 类比

类比只建立直觉，不等于真实机制。必要时补一句：“这个比喻只帮助理解其中一部分，真实工作方式更复杂。”

可用方向：
- 文件：一份具体作品/作业
- 文件夹：分类收纳盒
- 路径：找到某处的一串位置线索
- 算法：清楚、可执行的做事步骤
- 循环：按规则重复动作
- 条件判断：满足条件就执行某动作
- 变量：有名字、内容可以更新的记录位置/盒子（随后说明并非实体盒子）
- 数据包：被拆开发送的小块信息（随后说明网络机制更复杂）

避免永久化错误类比，如“CPU 就是大脑”“互联网就是公路”。
