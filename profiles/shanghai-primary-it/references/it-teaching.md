# 小学信息科技教学法

## 总原则

实践优先、问题驱动、可见思考、及时调试。学生应该有足够机会操作、解释、比较或创作，而不是只听软件按钮讲解。

## 基础数字技能

围绕真实任务操作，例如整理作品、查找文件、比较搜索结果、选择合适格式。不要把课堂退化成“记按钮在哪里”。

## 编程 / Scratch

推荐：`运行 → 预测 → 修改 → 调试 → 解释 → 创作`。

新概念可使用半成品程序、步骤卡、预期结果对照和结对调试，并逐步撤掉支架。

## 数据

推荐：`提出问题 → 收集/读取 → 整理 → 表示 → 找规律 → 解释结论`。

避免把“数据课”退化成 Excel/表格软件点击教程。

## 网络与安全

优先用情境判断和真实决策：个人信息、密码、陌生链接、网络交流、内容可信度、版权与来源。避免恐吓式教育。

## AI

推荐：`体验能力 → 观察错误 → 猜原因 → 简化原理 → 核验 → 隐私/版权/伦理 → 合理使用`。

不要把模型描述成具有人类意识、真正理解一切或永远正确。

## 计算思维

按任务自然使用：
- 分解：问题能拆成哪些步骤？
- 模式：哪里重复？和哪个旧问题类似？
- 抽象：哪些信息决定结果？
- 算法：怎样把方案写成别人也能执行的步骤？

不要每节课机械出现四个标题。

## 实际课堂 Plan B

涉及机房/网络/软件时，提前考虑：账号、浏览器/软件版本、文件保存、权限弹窗、网络不可用、投屏、素材离线备份、AI 服务登录与隐私限制。
